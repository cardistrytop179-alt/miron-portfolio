# Мирон | Веб-разработка, Telegram и автоматизация

Я делаю программные инструменты под конкретную задачу: собираю веб-панели для работы с данными, подключаю Telegram-ботов к внешним сервисам и автоматизирую повторяющиеся действия. В небольших проектах обычно веду работу от сценария пользователя до готового прототипа и инструкции по запуску.

В портфолио есть личные разработки с открытым исходным кодом и клиентские кейсы. Для клиентских и внутренних систем код остаётся закрытым: я указываю сайт, если он доступен, или описываю результат без ссылки на репозиторий.

[Скачать резюме в формате DOCX](./Резюме_Мирон.docx) · [Профиль GitHub](https://github.com/cardistrytop179-alt)

## Технологии

Python, JavaScript и TypeScript; Node.js, Express и Flask; React и Astro; PostgreSQL, SQLite и Prisma; Telegram Bot API и Mini Apps; Docker и GitHub Actions. Подключаю внешние API и собираю локальные или веб-инструменты для работы с CSV и аналитическими данными.

## Внутренние инструменты и интеграции

- **Помощник менеджера по заказам** — локальная веб-панель проверяет этапы заказа, загружает согласованные CSV-выгрузки, ищет товары и готовит черновики. Рабочие данные остаются на устройстве.
- **Парсер автомобильных объявлений для Telegram-сервиса** — извлекает параметры карточки и передаёт их боту; при блокировке обычного запроса использует браузерный сценарий.
- **Telegram LeadBot** — собирает открытые объявления о разработке, отбирает подходящие заявки и показывает их для проверки. Первое сообщение отправляется в выбранном режиме; после ответа диалог передаётся человеку.
- **Бот верификации участников** — проверяет правила реферальной программы и подписку перед выдачей доступа в закрытую группу.
- **Другие Telegram-системы** — боты для анкет, уведомлений, управления подписками и повторных обращений; MVP с API, панелью управления и Telegram Web App.
- **Исследовательские и торговые инструменты** — интерфейс для рыночных данных, бэктестеры, расчёт метрик и контроль риска. Результаты исследований не являются обещанием доходности.
- **Проверки безопасности** — согласованные проверки веб-приложений и отчёты владельцам. Названия ресурсов и детали тестирования не раскрываю.
