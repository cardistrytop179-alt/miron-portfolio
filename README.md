# Мирон — разработчик программных решений

Разрабатываю Telegram-ботов, веб-приложения и автоматизацию для бизнес-процессов. Подключаю внешние API, проектирую серверную логику и базы данных, собираю интерфейсы и готовлю решения к самостоятельному запуску.

- GitHub: [cardistrytop179-alt](https://github.com/cardistrytop179-alt)
- Основные технологии: Python, JavaScript/TypeScript, Node.js, React, Astro, Express, Telegram Bot API, Prisma, PostgreSQL, SQLite, Docker.
